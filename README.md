# opc-skill

给「一人公司 / 小微企业」用的 **Claude Code / Claude Agent Skill**：
把北京注册一家公司之后**必须自己搞定的政务流程**，连同踩过的坑，整理成可被 AI 直接调用的操作手册。

覆盖：**营业执照与工商变更（经营范围）· 税务报到与税种核定 · 个税扣缴月度申报 ·
社保单位登记与增员 · 住房公积金比例增员与委托收款 · 发薪与三条链口径对齐 · ICP 备案**。

内容全部来自在一个真实主体上从零跑通的过程 —— 不是抄办事指南，
重点是**指南上没写、但会让你卡住半天的那些东西**。

## 为什么需要这个

政务办事的官方指南只告诉你「有这个事项」，不告诉你：

- 事项之间的**依赖顺序**（公积金增员被比例卡，比例被委托收款卡，委托收款被对公户卡）
- 哪些"报错"其实是**正常的**（委托收款提交后「未缴款」要等银行托收日）
- 哪些"成功"其实**没成功**（提交没报错 ≠ 落库；要去列表页核对记录）
- 平台的**真实状态机**（变更登记从"待签字"到"办结"中间还有"审查中"）
- 同一条业务链上两个网站的**自动化姿势可能完全互斥**
- 同一笔工资在三个平台**填的不是同一个数**（应发 / 实发 / 个人扣缴部分），且**归属月份的口径互不相同**

这些是本 skill 的主体。

## 安装

```bash
git clone https://github.com/<你的账号>/opc-skill.git ~/.claude/skills/bj-company-affairs
```

或者放进项目的 `.claude/skills/` 下。之后直接问：

> 公司还有什么没做？
> 帮我看看经营范围变更生效了吗
> 这个月的个税零申报怎么弄
> 公积金比例怎么设
> 给自己发工资该走工资还是分红
> 这个月发薪，三个平台分别填什么数

## 隐私

**本仓库不含任何主体身份信息。** 公司名称、统一社会信用代码、身份证号、手机号、平台账号密码、
对公账号、联行号、业务流水号、各平台内部主体 ID、工资与缴费金额 —— 一律不在仓库里。

需要这些数据的地方，写的是「去你自己的私有档案取」。
`SKILL.md` §0 给了私有档案的**类目清单**（存什么，不含具体值），照着建一份放本地并加进 `.gitignore` 即可。

如果你 fork 之后往里填了自己的真实信息，**记得别推回公开仓库**。

## 适用范围与免责

- 地域：**北京**。其他省市平台不同，但**依赖顺序、义务日历、自动化姿势**这三块基本可迁移。
- 规模：小微企业（人数个位数）、查账征收、一人参保起步。
- 时效：政务平台改版频繁，**页面元素 id / 菜单路径 / 政策数值都会变**。
  本仓库记的是当时实测，**动手前先去平台核对当前状态**。
- 本仓库是**经验记录，不是法律或税务意见**。涉及金额、时限、罚则的地方请以官方原文和主管部门口径为准；
  文中标注了「未拿到原文，别当准数讲」的条目请特别注意。
- `payroll.md` 里的**预扣率表与个人缴费比例是写作时的口径**，逐年可能调整（基数上下限每年必调），
  用之前先核对当年官方公布值。
