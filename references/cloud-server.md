# 云服务器采购（备案前置）

买服务器这件事，在一人公司这里**不是技术选型问题，是备案的前置条件**。
所以先满足备案约束，再谈够不够用、贵不贵。

## 1. 备案对服务器的三条硬约束

| 约束 | 说明 |
|---|---|
| **境内** | 必须是境内节点（香港/海外节点不能备案） |
| **包年包月 ≥ 3 个月** | **按量付费的实例不能用来备案**，这是必须包年包月的第一个理由 |
| **开放公网 80/443** | 且要挂备案指向占位页，`http://<公网IP>/` 能返回 200 |

⇒ 顺序是：**先买机器 → 挂占位页 → 才能提备案**。想"先备案再买机器"是走不通的。

⚠️ 备案要求「备案账号与服务器所在账号是同一个云账号」。
⇒ 服务器买在哪个账号，备案就得在那个账号办；而一个账号只能装一个备案主体
（见 `icp-filing.md` §6）。**开账号前先想清楚这台机器将来给谁备案。**

## 2. 公网 IP 到底单收不单收

这条经常被报价方多算一笔。**两家官方口径已核实一致**：

- **包年包月 + 按固定带宽计费** ⇒ 计费项只有「公网网络费（带宽费）」，
  **不含 IP 保有费**。结算面板上就两项：配置费用 + 公网带宽费。
- 只有**按量付费**的两种模式才会另收「IP 配置费 / 公网 IP 保有费」。

⇒ 报价里公网 IP 列 **¥0 并注明「含在带宽费内」是准确的**。
这也是坚持包年包月的第二个理由（第一个是备案不认按量付费）。

## 3. 询价：总价必须拆三段算

**别信任何"一台服务器多少钱一年"的单一数字。** 实际总价是三段相加：

```
实例配置费  +  云盘费  +  公网带宽费  =  年费
```

三段各有各的坑：

- **实例**：同样 4C8G，**共享型 / 通用算力型 / 独享计算型**差价可达 2 倍以上。
  能接受共享型 CPU 的话，一年能省下大半。备案占位页、小流量官网用共享型完全够。
- **云盘**：入门级云盘常有**实例系列绑定限制**（某些便宜盘只有特定实例系列能挂），
  选了贵实例反而挂不上便宜盘。
- **带宽**：小带宽是**阶梯定价**，前几 Mbps 每档递增较缓，到某个档位之后改成
  "每 Mbps 固定单价"、单价明显跳高。**带宽常常是三段里最贵的一段**，
  按实际需要买，别顺手拉到 10M。流量计费 vs 固定带宽哪个划算取决于流量形态，先估月流量再选。

⇒ 记账时**把三段分开记，并写上询价日期**。云厂商折扣（1 年 X 折、3 年 Y 折）变动频繁，
过期的总价数字比没有更糟。

## 4. 抓价格页的坑

云厂商的价格计算器页面：

- **antd tabs 的非活动 `.ant-tabs-tabpane` 仍然留在 DOM 里** ⇒ 直接取 `innerText`
  会读到**上一个 tab 的旧内容**。必须先过滤 `className.includes('active')`。
- 实例价格表的**列顺序容易看错**（按量目录价 / 包月目录价 / 包周 / 按量月价 /
  包月折扣价 / **年付月价** / 3年付月价 / 5年付月价）。要的是"年付月价"那一列，
  ×12 才是年费。**数错一列能差出一倍。**

## 5. 够用就好

一人公司在备案阶段真正需要的只是"一台能开 80/443、挂得住 nginx 的境内机器"。

- 备案占位页 + 官网静态站：最低配共享型足够
- 跑后端 API / 小模型推理再单独评估，**不要在备案这一步就买大机器**
- 包年包月到期会**停机**，续费提醒要设日历（备案信息里绑的就是这台机器，
  机器没了备案会被管局核查到"网站无法访问"）
