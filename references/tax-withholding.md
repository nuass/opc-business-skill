# 个税扣缴申报（自然人电子税务局 扣缴端）

## 0. 为什么只能用 Windows 客户端

- 企业电子税务局搜「个人所得税」「个税」「综合所得」「人员信息」**全部无结果**
  （对照组「财务报表」「核定」有结果 ⇒ 搜索本身正常）⇒ **企业端网页没有个税模块**。
- 自然人电子税务局网页 `etax.chinatax.gov.cn` 只有自然人业务（年度汇算/专项附加扣除/经营所得），
  **没有扣缴义务人入口**。
- ⇒ 人员信息采集 + 综合所得扣缴申报 必须用 **自然人电子税务局（扣缴端）Windows 客户端**：
  `https://file.etax.chinatax.gov.cn/bbxzdownload/kjkhd/ETax.exe`（约 163MB，PE32，macOS 跑不了）。

客户端跑在一台（可能是远程的）Windows 机上，接入方式记进你自己的私有档案。

## 1. 登录

卡在「离线模式」且没有申报密码时，**解法不是找申报密码，而是让本人用「个人所得税」APP 扫客户端二维码实名登录**。
⚠️ 切到在线后客户端会重启，**hwnd 会变**，自动化脚本必须重新 `FindWindow`。

## 2. 人员信息采集

左侧导航「人员信息采集」→ 添加 → 填 姓名 / 证件类型 / 证件号码 / 性别 / 出生日期 / 手机 /
**人员状态=雇员** / **任职受雇日期** → 保存 → **报送**。
成功标志：报送状态「报送成功」+ 身份验证状态「验证通过」。

**⚠️ 任职受雇日期必须与劳动合同起始日、社保参保起始月对齐。** 三者不一致的后果：
税务口径认为某月已是本公司员工，而该月本公司无社保 ⇒ 形式上构成「用工未参保」
（社保法要求用工之日起 30 日内参保）。零申报月份改日期无代价，发现就改。

**改错记录就地改**：双击网格里的姓名单元格打开 `TfrmNsrEditView` 编辑，**不要删了重建**
（界面上没有直接删除按钮，删除要走「更多操作」，步骤多风险大）。

## 3. 月度综合所得申报

四步向导：① 收入及减除填写 → ② 税款计算 → ③ 附表填写 → ④ 申报表报送。

### 未发薪 ⇒ 零申报

**「零申报」不等于「什么都不填」。** 空表在第 4 步会被拦：`当前月份申报数据未填写！`、是否可申报=否。
必须先在 步骤1 → 正常工资薪金所得 → 添加 建一条**本期收入 0.00** 的明细。

流程：添加 → 姓名（选建议项）→ 本期收入 0.00 → 保存 → 步骤2 重新计算 → 步骤4 发送申报 → 立即获取反馈。
成功标志：申报状态「**申报成功，无需缴款**」，反馈「【综合所得预扣预缴表】反馈结果：申报成功」，
应补（退）税额 0.00，按钮区变成 获取反馈 / 作废申报 / 更正申报。

### 已发薪 ⇒ 正常申报，不能照抄零申报

- 本期收入填**当月实际发放的「应发」（税前）工资总额** ——
  ⚠️ **不是打到卡里的实发数**。个人承担的三险一金在下面单独作为减除项填，
  这里再填实发就等于扣两遍、收入还少报了。「实发」在这里只用来判断"钱有没有真发"，不是填进表的数；
- 并填「基本养老保险费 / 基本医疗保险费 / 失业保险费」的**个人部分**（精确数以社保实际扣缴额为准）；
- 填了三险后算税时不再弹「未填写三险一金」提示；
- **累计减除费用按已申报月份数累计，零申报月份也算一个月**
  （如 7 月做了零申报，8 月首次正常申报时累计减除已是两个月的量）。
  收入低时这一项往往单独就覆盖应纳税所得额、算出来税为 0，不必依赖专项附加扣除撑着；
- **归属月份按钱实际打出去的那个月**，与工资"所属月份"无关（1 月发 12 月工资 ⇒ 1 月所得）；
- 判据只有一条：**对公户有没有真把钱打到个人卡。只做账不打钱不能按发薪申报**（虚列成本）。

⇒ 数怎么算出来、什么时候打款、三个平台分别填哪个数：见 `payroll.md`。

### 常见弹窗

| 弹窗 | 处理 |
|---|---|
| `未填写三险一金，请确认是否继续？` | 零申报时点「继续算税」/「继续申报」 |
| `未获取到 YYYYMM 月份的申报信息` | 新登记单位可直接忽略，点确定 |
| 姓名输入后的 `Tfrm_IntelligentSearchPop` | **必须点选建议项**才会带出证件号码；光打字证件号会留空。表单取消会整条清空 |

## 4. GUI 自动化四个必踩坑（远程 Windows + PowerShell P/Invoke）

1. **schtasks 拉起的 cmd 控制台会抢前台挡住表单，吞掉合成点击**（表现：点了没反应）。
   每个脚本开头必须
   ```
   [DllImport("kernel32.dll")] GetConsoleWindow()  →  ShowWindow(cw, 0)
   ```
   点击前再对目标窗口 `BringWindowToTop` + `SetForegroundWindow`。
2. **schtasks 必须 `/it /rl HIGHEST`** 才会拿到 InteractiveToken 落在 Session 1；
   否则进程在 Session 0，远控里根本看不到窗口。
3. **每个 `Add-Type` 必须用全新类名**（同一会话内重复定义会报类型已存在）；脚本存盘用 `utf-8-sig`。
4. **验证只用本地 OCR**：把远程截图 `scp` 回 Mac 再跑 PaddleOCR，
   **绝不用 Read 工具直接看 1920x1080 远程截图**（token 开销大且看不清小字）。
5. **客户端是 Delphi 原生控件**：网格滚动对它发 `WM_VSCROLL` 消息；关查看/详情页发 `WM_CLOSE`；
   扫码登录的**二维码会定时轮换**，脚本取到码要尽快让用户扫，别存着稍后扫。

## 5. 关键坐标

这个客户端是 Delphi 写的，**没有可用的 accessibility 树 / DOM，只能靠固定坐标点**。
⇒ 必须自己维护一张坐标表（放私有档案），并且**表头写清「客户端版本号 + 屏幕分辨率」**，
用前先核对这两项有没有变 —— 变了整张表作废。

要覆盖的坐标：

- 左侧导航：人员信息采集、综合所得申报
- 人员采集网格首行「姓名」单元格 → **双击** 打开 `TfrmNsrEditView`
- 报送 → 报送确认「确定」→ 报送结果 `TfrmBase`「关闭」
- 申报向导 4 个 tab、`TFrm_YJYKReportEdit` 明细编辑框、`Tfrm_FeedbackWaiting`「立即获取」
