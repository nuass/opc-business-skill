# 企业电子税务局（北京）

门户：`https://etax.beijing.chinatax.gov.cn:8443/`
统一登录：`tpass.beijing.chinatax.gov.cn`
首次登录：**电子营业执照**扫码（法定代表人用微信/支付宝「电子营业执照」小程序扫屏幕二维码 → 执照密码 → 人脸）

## 1. 新办纳税人前置清单（按依赖顺序）

1. **税务登记 / 税务信息确认 —— 成立后 30 天内**，完成后有《税务事项通知书》PDF 可下载存档
2. **税种（税费种）核定确认** —— 查询路径见 §2
3. **三员实名采集**：法定代表人 / 财务负责人 / 办税人。用「个人所得税 APP」或「北京市电子税务局 APP」人脸实名
4. **财务会计制度备案 —— 15 天内**，小微一般选「小企业会计准则」
5. **对公账户开户**（银行线下/线上）→ 开户后回税务局做**存款账户账号报告**（三方协议验证依赖它）
6. **网签三方扣款协议** —— 依赖对公户，没户做不了；需要开户行 + 对公账号。
   **签完要在协议列表看到「验证通过」才算能用**（没验证过的协议在缴款页选不到）。
   ⚠️ **联行号别和公积金的搞混**：税务三方协议用**银行级（分行）联行号**，
   公积金委托收款用**网点联行号**，两者不是同一个号，各记各的、别互相覆盖着填。
7. **票种核定 + 税务 UKey 申领** —— UKey 邮寄 3–5 天

⚠️ 登录时报「统一社会信用代码或纳税人识别号错误」，先检查 18 位代码里的 **数字 0 被打成字母 O**。

## 2. 查税种核定明细

路径：**我要查询 → 一户式查询 → 纳税人信息查询 → 税费种认定信息**
（不在「涉税信息查询」下面。hover 菜单会收起，见 §4）

同一页还能看：
- **核定征收信息 = 暂无数据** ⇒ 企业所得税是**查账征收**，不是核定征收
- 主管税务机关（具体到税务所）、纳税信用等级

典型小微科技公司的 9 项核定长这样：

| 征收项目 | 纳税期限 | 征收方式 |
|---|---|---|
| **个人所得税**（工资薪金所得） | **月** | **代扣代缴** |
| 增值税 | 季 | 自行申报 |
| 企业所得税 | 季 | 自行申报 |
| 城建税 / 教育费附加 / 地方教育附加 | 季 | 自行申报（增值税附征） |
| 印花税（营业账簿） | 年 | 自行申报 |
| 残疾人就业保障金 | 年（次年 9/30） | 自行申报 |

**推论**：唯一的月度义务是个税扣缴申报，其余全是季/年。
这也解释了为什么企业电子税务局「本期应申报」经常显示暂无数据 —— **个税不在企业端**，在扣缴端客户端。

## 3. 社保费在这里缴，不在人社

- 人社只管「参保登记/增减员/备案」，**社保费的申报缴费工资和实际缴款都在电子税务局**。
- 模块：职工参保信息管理 / 社保费申报。
- ⚠️ 增员**之前**打开会报「您尚未进行社保费缴费信息关联」⇒ 必须先完成增员（主通道见 `social-insurance.md` §1）。
- 时间：参保登记成功的**次月 10 日起**申报缴费工资。
- ⚠️ etax 会话约 **15–20 分钟**就过期（新开功能页会被打回 tpass 登录页），自动化操作要紧凑。

### 查参保状态的唯一入口：职工参保信息管理

热门服务【社保费业务】→ **职工参保信息管理**（`#/zgcbxxClient`）→ 行尾【详情】。
一张表看全五险（人社三险 + 医保两险一起显示，但**单位编号不同**：人社侧一个号、医保侧一个号）。
增员后隔几天来这儿核实**五险是否都挂上**，比任何回执都硬 —— 只挂三险就是医保没过来，
回 `social-insurance.md` §1/§5 补。

### ⚠️「应缴信息查询」永远空，能不能缴看「日常申报」

「社保费应缴信息查询」`#/yjxxcx` 长期显示「没有查询到有效的单位应缴信息」—— **这不代表没账单**。
待申报数据在 **日常申报 `#/sbfrcsb`** 里。判断「能不能缴」看日常申报，别看应缴信息查询。

**缴费点击链**（Ant Design 2 / React 15）：
日常申报 → 勾表头全选 →【提交申报】（`button.ant-btn-primary.filter-btn`，直接点，不是 hover 菜单）
→ 弹「系统将在十几秒后自动获取申报结果」自己会走完 → 跳申报记录 `#/dwsbjlcx`
（**要手点查询才出数据**）→ 行尾【缴款】（⚠️ 是 `div.operate` 不是 a/button，选择器必须带 `div`）
→ 支付方式选【三方协议】和对公账号 →【确定】→「三方协议缴款扣款成功」。

**独立验证**：缴费记录 `#/dwjfjlcx` 每条应为 缴费成功 / 三方协议支付，同一张电子税票号，
核对缴费期限未逾期、滞纳金 0.00。

### 医保账单迟迟不出来：先查基数是不是空的（根因级）

日常申报医保侧报 **「无有效的汇总预处理信息」**，先别怀疑医保中心没推核定 ——
新参保人员最常见的根因是**医保两险的缴费基数根本没报上**：

1. 热门服务【社保费业务】→ **职工参保信息管理**（`#/zgcbxxClient`）下载
   **参保职工列表（按险种）**，看该人员的**职工基本医疗保险 / 职工大额医疗互助保险两列基数**。
2. 两列为空 ⇒ 医保账单永远不会生成，走下一节「年度缴费工资调整」按人补上。
3. 基数已报成功（申报记录 `#/gzsbjl2` 能查到工资调整记录）仍空 ⇒ 才是等核定批次（见再下一节）。

### 基数为空的修法：年度缴费工资调整（按人员单个录入）

入口：**缴费工资申报 → 年度缴费工资调整**（`#/ysbgztz2`）。
⚠️ **增员次月 10 日起才可操作**（提前操作不生效）；以后每月有新增人员、
当月出不来数的，都要按人调一次。

1. 页面切到 **「按人员申报缴费工资」** 模式（切模式会清空已填草稿，网格空时再切）。
2. 【添加】→ **单个录入** → 选证件类型、填证件号回车带出人员。
3. **原缴费工资**由系统自动带出，填 **新缴费工资**（按下限交就填**当年度医保基数下限**，
   当年数值记私有档案；填高了按实际工资核定）。
4. 【保存】→ 列表核对两险新基数 →【提交申报】→ 范围选「全部数据」→ 弹框【确认】。
5. 验证：申报记录 `#/gzsbjl2` 查到「申报成功」的工资调整记录。

⛔ **外部文件导入对医保列无效**：导入只写人社三险；网格里医保两列是纯文本 `--`、
不可编辑，导入提示成功也不会把数带进去。医保只能走上面的按人单个录入。

### 基数报完后：等核定批次，别重复操作

工资调整申报成功后，医保核定要经批处理推送到税务（通常当天下午到隔夜）。
这期间日常申报医保侧仍报「无有效的汇总预处理信息」**不代表失败**，
过半天或次日再查，不用反复重报。

### 日常申报查询：两个下拉要按险种侧配对选

查询条件里**单位编号**有两个（人社侧一个、医保侧一个），**社保经办机构**也有
人社/医保两个选项 —— 查医保账单时两个都选**医保侧**、配对选，
选错就是「查询失败 / 无数据」的假阴性。再选费款所属期后点查询。

**每月把日常申报里两类险种都核一遍，别缴完三险就当完事。**

### 基数低于下限会被静默核定

申报的缴费工资低于**当年度**下限时，系统不报错、直接按下限核定
（年度切换后旧下限值直接作废，曾出现核定基数高于申报工资的情况）。
⇒ 算钱、报个税的三险一金数都按**税务实际核定基数**来，别按自己申报的工资算。

## 4. hover 菜单自动化坑

- mega menu 只在鼠标停在顶部导航项时存在；鼠标一离开就收起，且**导航项与展开面板的 x 范围不重叠**，
  没有连续鼠标路径可走。
- 面板内元素 `innerText` 返回**空字符串**，必须用 `textContent` 匹配。
- **可行解**：真鼠标 `mouse.move` 停在顶部导航项 → 在一次 `async evaluate` 内对二级项
  dispatch `mouseover/mouseenter/mousemove` → `await sleep(2200)` → 再对三级项 dispatch `click`，
  全程不再动真鼠标。
- 搜索框 `input[placeholder='请输入关键词']` **只索引「我要办税」事项**，查询类菜单搜不到 ——
  搜不到不等于没有这个功能。
